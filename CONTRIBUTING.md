# Contributing to Eternal Elusion

Thank you for your interest in Eternal Elusion!

Please note that this repository is maintained as a personal project and its **issue tracker is closed**. At this time, **I do not accept pull requests, feature requests, or external code contributions**.

## Can I still use and modify it?

Yes! Eternal Elusion is open-source software licensed under the [MIT license](./LICENSE). You are free to download, inspect, fork, and modify the source code, and maintain your own independent version.
